## ATLAS REFERENCES｜圖譜參照

背部區域包含背部的淺層肌肉、中層肌肉與深層肌肉。這些肌肉皆附著於脊柱。脊柱具有雙重功能：構成身體的中軸，並為脊髓提供保護性的骨性覆蓋。

## SURFACE ANATOMY｜表面解剖

本區域的表面解剖可在活體或大體標本上進行研究。在大體標本上，固定處理可能使骨質與保存良好的軟組織難以區分。將大體標本擺為俯臥位（面部朝下），並嘗試觸摸以下結構（圖 1.1）：*[G 322; L 5; N 149; C 325]*

- 枕外隆凸（External occipital protuberance）
- 斜方肌上部（Superior border of the trapezius muscle）
- 第七頸椎棘突（Spinous process of C7，脊椎隆起，vertebra prominens）
- 肩胛岡（Spine of the scapula，位於 T3 椎體水平）
- 肩峰（Acromion of the scapula）
- 肩胛骨內側（椎）緣（Medial (vertebral) border of the scapula）
- 肩胛骨下角（Inferior angle of the scapula，位於 T7 椎體水平）
- 胸椎棘突（Spinous processes of thoracic vertebrae）
- 豎脊肌（Erector spinae muscle，於腰椎區最明顯）
- 正中溝（Median furrow）
- 背闊肌外側緣（後腋皺褶，Lateral border of the latissimus dorsi muscle）
- 髂嵴（Iliac crest，位於 L4 椎體水平）
- 髂後上棘（Posterior superior iliac spine）

## SKELETON OF THE BACK｜背部骨骼

參照骨架標本。於肩胛骨上辨識以下結構（圖 1.2）：*[G 483; L 32; N 408; R 371; C 112]*

- 肩峰（Acromion）
- 肩胛岡（Spine）
- 上角（Superior angle）
- 內側（椎）緣（Medial (vertebral) border）
- 下角（Inferior angle）

### 典型胸椎（圖 1.3）*[G 292; L 6; N 151; R 193; C 392]*

- 椎體（Body）
- 椎弓（Vertebral arch）——由椎根（pedicles）與椎板（laminae）組成
- 椎根（Pedicle）×2
- 椎板（Lamina）×2
- 椎孔（Vertebral foramen）
- 橫突（Transverse process）×2
- 橫突肋凹（Transverse costal facet）
- 棘突（Spinous process）
- 關節突——上關節突與下關節突（Superior and inferior articular processes）
- 椎骨上下切跡——椎上切跡與椎下切跡（Superior and inferior vertebral notches）
- 肋凹——上肋凹與下肋凹（Superior and inferior costal facets）

胸椎的棘突細長，向下方延伸覆蓋於下位椎骨的棘突之上。與肋骨關節連結是胸椎的特徵。肋骨頭關節於兩個相鄰椎體之間（圖 1.4）。肋骨結節關節於同序號胸椎的橫突肋凹上。椎間盤與關節突將兩相鄰椎骨連接。兩個相鄰椎骨的椎骨切跡共同構成椎間孔，脊神經由此通過。

### 頸椎與腰椎的比較（圖 1.5）*[G 298; L 7; N 19; R 190; C 388]*

頸椎與胸椎的差異：
- 椎體較小
- 椎孔較大
- 棘突較短，末端分叉
- 橫突含有橫突孔（Foramen transversarium）

個別頸椎的特徵：
- **寰椎（C1）**：無椎體
- **樞椎（C2）**：有齒突（dens），為 C1 椎體於發育期間融合至 C2 所形成
- **隆椎（C7）**：頸椎中棘突最顯著者，即「脊椎隆起」之意

腰椎與胸椎的差異：
- 椎體較大
- 棘突寬闊，向後突出
- 無橫突肋凹

### 骶骨與尾骨（圖 1.6）*[G 314; L 12; N 154; R 191; C 399]*

骶骨由五節融合的椎骨組成，無明顯的棘突或橫突。於骶骨後表面辨識：
- 正中骶嵴（Median sacral crest）
- 骶後孔（Posterior (dorsal) sacral foramina）
- 骶管裂孔（Sacral hiatus）

尾骨是由四節退化的尾椎融合而成的三角形小骨。

### 髂骨與枕骨的特徵

於髂骨上辨識（圖 1.2）：*[G 317; L 5; N 474; R 188]*
- 髂嵴（Iliac crest）
- 髂後上棘（Posterior superior iliac spine）

於枕骨上辨識（圖 1.2）：
- 枕外隆凸（External occipital protuberance，inion）
- 上項線（Superior nuchal line）

於顳骨上辨識（圖 1.2）：
- 乳突（Mastoid process）

## SKIN AND SUPERFICIAL FASCIA｜皮膚與淺層筋膜

### 解剖概覽

解剖順序如下：
1. 將皮膚自背部、頸後表面及近端上肢後表面剝離。
2. 觀察後皮神經。
3. 移除淺層筋膜。

### 解剖步驟

#### 皮膚切口（圖 1.7）

1. 參照圖 1.7。
2. 使用手術刀，自枕外隆凸（X）至尾骨尖（S），沿正中線做皮膚切口。本區域皮膚厚度約 6 公釐。
3. 自尾骨尖（S）至腋中線（T）做一切口，約通過髂嵴下方 3 公分處。
4. 自枕外隆凸（X）至乳突基部（M）做一橫向皮膚切口。
5. 沿頸外側及斜方肌上部表面做皮膚切口（M 至 B），延伸至手臂中點附近（F 點）。
6. 於 F 點做繞行切口，繞過手臂前、後表面，於內側會合（G 點）。
7. 自手臂內側表面 G 點起始，向上延伸至腋窩。再沿軀幹外側面向下延伸，經 V 至 T。
8. 於肩胛骨下角水平，自正中線（U）至腋中線（V）做一橫向皮膚切口。
9. 為方便剝皮，於上述切口上下方做數條平行的橫向切口，各皮膚條帶約寬 7.5 公分，以利剝皮操作。
10. 自內側至外側剝離皮膚。將剝離的皮膚置入組織收集容器中。

#### 淺層筋膜

1. 於淺層筋膜中，找出枕動脈與枕大神經（圖 1.8）。先找到枕動脈，再於其內側尋找枕大神經。枕大神經為脊神經 C2 的後（背側）支。枕大神經穿斜方肌，約於枕外隆凸外下方 3 公分處穿出。本區域深層筋膜緻密堅韌，即使是大神經也可能難以找到。*[G 323; L 16; N 172; R 226; C 382]*
2. 閱讀脊神經後（背側）支的描述。後支的後皮支穿斜方肌或背闊肌進入淺層筋膜（圖 1.9）：*[G 22; L 21; N 185; R 229]*。為節省時間，不需特意顯露後支的後皮支。
3. 自內側至外側反射背部淺層筋膜。沿皮膚切口線切割，將淺層筋膜置入組織收集容器中。
4. 於頸部，淺層筋膜僅反射至斜方肌上部外側。勿切割斜方肌上部的深層筋膜。副神經（accessory nerve）於此處淺層通過，有受損風險。

## SUPERFICIAL MUSCLES OF THE BACK｜背部淺層肌肉

### 解剖概覽

背部淺層肌肉包括：斜方肌、背闊肌、大菱形肌、小菱形肌與肩胛提肌。

解剖順序如下：
1. 清理斜方肌淺面及邊界並進行觀察。
2. 將斜方肌翻開檢視。
3. 觀察並翻開背闊肌。
4. 辨識大菱形肌、小菱形肌與肩胛提肌。
5. 淺層背部肌肉應兩側均進行解剖。

### 解剖步驟

#### 斜方肌（圖 1.10）*[G 323; L 17; N 168; R 226; C 373]*

1. 清除斜方肌表面的脂肪及結締組織（斜方肌之拉丁文「trapezoides」意為不規則四邊形）。清晰顯露其下外側界，但勿擾及上外側界。觀察斜方肌的內側附著處：枕外隆凸、項韌帶及 C7 至 T12 的棘突。
2. 觀察斜方肌於鎖骨及肩胛骨上的外側附著處。斜方肌分為三部，各有不同的功能：
   - **上部**：附著於鎖骨外三分之一，功能為提肩胛。
   - **中部**：附著於肩峰及肩胛岡，功能為後拉肩胛。
   - **下部**：附著於肩胛岡內側端附近，功能為降肩胛。
3. 準備翻開斜方肌。首先將手指插入肌肉下外側界深面（肩胛骨下角內側），向上盡量遊離，以切斷介於斜方肌與深層背部肌肉之間的結締組織。
4. 使用剪刀自棘突及項韌帶附著處（圖 1.10 虛線）將斜方肌切斷。自肌肉下端開始，向上切至枕外隆凸。
5. 使用剪刀做一短橫切口（約 2.5 公分）於斜方肌上部，切斷其於上項線的附著。保留枕大神經，橫切口勿超出斜方肌上外側界。
6. 使用剪刀自肩胛岡及肩峰上的外側附著處（圖 1.10 虛線）將斜方肌切斷。切口盡量靠近肩胛岡。保留附著於鎖骨及頸部筋膜的斜方肌部分。
7. 將斜方肌翻向上外側。保留頸部筋膜於斜方肌上界作為鉸鏈。
8. 觀察翻開斜方肌的深面。找出由副神經（腦神經 XI）與 C3、C4 前（腹側）支所構成的神經叢。副神經支配斜方肌的運動功能；C3、C4 分支為感覺神經（本體感覺）。橫頸淺支伴行這些神經。橫頸靜脈可移除以清楚視野。
9. 副神經穿經頸後三角，現階段勿跟隨神經進入頸後三角。頸後三角將於頸部解剖時一併處理。

#### 背闊肌 *[G 323; L 17; N 168; R 226; C 373]*

1. 清理背闊肌表面及邊界（拉丁文「latissimus」意為最寬）。
2. 背闊肌的內側附著處為 T7 至 T12 的棘突、胸腰筋膜及髂嵴。背闊肌亦附著於第 9 至 12 肋骨（靠肋骨角外側）。
3. 背闊肌的外側附著處為肱骨前面結節間溝底，但現階段不解剖。背闊肌於其外側附著處附近的前表面接受胸背神經與胸背動脈支配。此等神經與血管將於上肢解剖時一併處理。
4. 翻開背闊肌：將手指插入肌肉上界深面（肩胛骨下角內側），遊離疏鬆結締組織平面，使背闊肌與深層肌肉分開。遊離足夠空間後，使用剪刀切斷其於胸腰筋膜及下位胸椎棘突上的內側附著（圖 1.10 虛線）。勿靠近腰椎棘突切割，應於肌肉纖維附著於胸腰筋膜處切斷。
5. 將背闊肌翻向外側。勿擾及其肋骨附著處。若有附著於肩胛骨下角，亦保留不動。

#### 大菱形肌與小菱形肌 *[G 324; L 17; N 171; R 226; C 373]*

1. 清理菱形（小菱形肌與大菱形肌，希臘文「rhombos」意為風箏形）表面及邊界。
2. 小菱形肌的內側附著處為項韌帶及 C7、T1 的棘突；外側附著處為肩胛岡水平的肩胛骨內側緣。
3. 大菱形肌的內側附著處為 T2 至 T5 的棘突；外側附著處為肩胛岡下方的肩胛骨內側緣。
4. 通常兩菱形肌之間的分界不太明顯，需以它們的外側附著處為指引來分離。
5. 菱形肌的功能為後拉肩胛、旋轉肩胛使關節盂向下，並使肩胛骨緊貼胸廓。
6. 翻開菱形肌：將手指插入大菱形肌下界深面，與深層肌肉遊離。自下而上使用剪刀切斷大菱形肌於棘突上的內側附著，繼續向上切斷小菱形肌於棘突上的內側附著。將兩肌肉翻向外側（圖 1.10）。
7. 於兩菱形肌深面近外側附著處，使用鈍剝找出肩胛背神經與肩胛背血管。肩胛背神經與血管沿肩胛骨內側緣並行。
8. 肩胛背動脈可自鎖骨下动脉直接發出，亦可自橫頸动脉發出（此時亦稱為橫頸动脉深支）。

#### 肩胛提肌 *[G 324; L 17; N 168; R 222; C 373]*

1. 辨識肩胛提肌（拉丁文「levare」意為提起）。在此解剖階段，肩胛提肌僅能於其肩胛骨附著處附近觀察到。
2. 肩胛提肌的上內側附著處為上位四節頸椎的橫突。不需解剖其上方附著處。
3. 肩胛提肌的下外側附著處為肩胛骨上角。
4. 肩胛背神經與肩胛背动脉供應肩胛提肌。它們於肩胛提肌下端的深面（前方面）通過。
5. 肩胛提肌的功能為提肩胛，並旋轉肩胛使關節盂向下。

### 解剖後續

1. 將背部淺層肌肉恢復至正確解剖位置。
2. 利用已解剖標本複習各肌肉的附著處、動作、神經支配及血液供應。
3. 複習肩胛骨與胸廓之間的運動。
4. 利用圖示觀察橫頸动脉及肩胛背动脉的起源。
5. 觀察與背闊肌相關的兩個三角形：聽診三角與腰三角（圖 1.10）。

## INTERMEDIATE MUSCLES OF THE BACK｜背部中層肌肉 *[G 324; L 17, 18; N 168; R 228; C 374]*

背部中層肌肉為上後鋸肌與下後鋸肌。上後鋸肌與下後鋸肌皆為極薄的肌肉，可能於解剖菱形肌或背闊肌時已被意外翻開。

若未見後鋸肌，請於翻開的菱形肌或背闊肌深面尋找。

1. **上後鋸肌**的內側附著處為項韌帶及 C7 至 T3 的棘突；外側附著處為第 2 至 5 肋骨的上緣（靠肋骨角外側）。
2. **下後鋸肌**的內側附著處為 T11 至 L2 的棘突；外側附著處為第 9 至 12 肋骨的下緣（靠肋骨角外側）。
3. 後鋸肌為呼吸（吸氣）肌肉，由肋間神經支配。

## DEEP MUSCLES OF THE BACK｜背部深層肌肉

### 解剖概覽

背部深層肌肉作用於脊柱。背部深層肌肉數量眾多（圖 1.11），本實習僅解剖其中部分：頭棘肌、頸棘肌、頭半棘肌及豎脊肌。所有背部深層肌肉皆由脊神經後支支配。

解剖順序如下：
1. 觀察並翻開頸後深層肌肉（頭棘肌與頸棘肌）。
2. 辨識頭半棘肌。
3. 解剖豎脊肌，辨識組成其三部（柱）的肌肉。

### 解剖步驟

#### 頭棘肌與頸棘肌（圖 1.10）*[G 325; L 18; N 168; R 226; C 376]*

1. 將上後鋸肌自 C7 至 T3 棘突切開，翻向外側，保留其於肋骨的附著。
2. 辨識頭棘肌（希臘文「splenion」意為繃帶，圖 1.10）。頭棘肌纖維斜向通過頸部。頭棘肌的下端附著於項韌帶及 C7 至 T6 的棘突。
3. 頭棘肌依其上端附著處分為兩部：
   - **頭棘肌（Capitis）**（拉丁文「caput」意為頭）——附著於顳骨乳突及枕骨上項線
   - **頸棘肌（Cervicis）**（拉丁文「cervix」意為頸）——附著於 C1 至 C4 的橫突
4. 頭棘肌的兩部在此解剖階段不易區分。將頭棘肌自項韌帶及 C7 至 T6 棘突的下端附著處切開。
5. 將肌肉翻向外側，保留其上端附著處不動。

#### 頭半棘肌 *[G 326; L 19; N 169; R 222; C 377]*

1. 辨識頭半棘肌（拉丁文「semi」意為一半；拉丁文「spinalis」意為脊柱，圖 1.11）。頭半棘肌是橫突棘肌群中最淺層的成員，位於頭棘肌與頸棘肌深面，其纖維垂直並行於脊柱。
2. 頭半棘肌的下端附著於上位胸椎的橫突。
3. 頭半棘肌的上端附著於枕骨上、下項線之間的區域。注意：枕大神經穿經頭半棘肌。
4. 現階段不解剖頭半棘肌的其餘部分。
5. 現階段不解剖橫突棘肌群的其他肌肉。

#### 豎脊肌（圖 1.11）*[G 325; L 18; N 169; R 222; C 377]*

豎脊肌（拉丁文「erector」意為豎立者）位於中層肌肉深面，由三柱肌肉組成：棘肌、最長肌與髂肋肌。本解剖的目的為辨識此三柱肌肉（圖 1.11）。

1. 將下後鋸肌自 T11 至 L3 棘突的內側附著處切開，翻向外側，保留其於肋骨的附著。
2. 使用手術刀切開胸腰筋膜後表面，自胸部中段延伸至骶骨。胸椎水平的筋膜很薄，但腰椎與骶骨水平則非常厚。使用鈍剝將胸腰筋膜與豎脊肌後表面分離。移除胸腰筋膜，置入組織收集容器。
3. 自胸部中段開始，使用手指分離豎脊肌的三柱。盡量繼續向下分離。豎脊肌於骶骨及髂骨水平相互融合，下方不易分離。
4. 辨識（圖 1.11）：
   - **棘肌（Spinalis muscle）**：豎脊肌的最內側柱。棘肌的下端附著於棘突，上端亦附著於棘突。棘肌存在於腰椎、胸椎及頸椎各層級。
   - **最長肌（Longissimus muscle）**（拉丁文「longissimus」意為最長）：豎脊肌的中間柱。下端附著於骶骨，上端附著於胸椎與頸椎的橫突。其最上端部分（即頭最長肌）附著於顳骨乳突。
   - **髂肋肌（Iliocostalis muscle）**：豎脊肌的最外側柱。下端附著於髂骨（髂嵴），上端附著於肋骨（拉丁文「costa」意為肋骨）。
5. 兩側豎脊肌同時收縮可使脊柱伸展；若僅單側收縮，則可使脊柱向收縮側側屈。

#### 橫突棘肌群 *[G 328; L 19; N 170; R 223; C 378]*

橫突棘肌群位於豎脊肌深面。群內肌肉附著於橫突與棘突（圖 1.11）。橫突棘肌群的作用為造成相鄰椎骨之間的旋轉與側屈運動，並穩定脊柱。本肌群包括：半棘肌、多裂肌及更深的旋轉肌。

### 解剖後續

利用已解剖標本複習深層背部各肌肉（或各柱肌肉）的位置、神經支配及功能。

## TRIANGLES OF THE BACK｜背部三角形 *[G 323, 324; L 17; N 248; C 373]*

**聽診三角**的邊界為：背闊肌、斜方肌與大菱形肌。聽診三角內，第 6 肋間隙無肌肉覆蓋，是聽診（ listen to sounds produced by thoracic organs，特別是肺部）的理想位置。

**腰三角**的邊界為：背闊肌、腹外斜肌與髂嵴。腰三角的底為腹內斜肌。臨床上，偶爾可見腰三角處發生腰疝（lumbar hernia）。

## SUBOCCIPITAL REGION｜枕下區

### 解剖概覽

於顱骨上辨識（圖 1.2）：*[G 698; L 300, 301; N 10; R 32; C 591]*
- 上項線（Superior nuchal line）
- 下項線（Inferior nuchal line）
- 枕外隆凸（External occipital protuberance）
- 枕骨大孔（Foramen magnum）

於寰椎（C1）上辨識（圖 1.12）：*[G 299; L 7; N 19; R 200; C 388]*
- 後結節（Posterior tubercle）
- 後弓（Posterior arch）
- 椎动脉溝（Groove for the vertebral artery）
- 橫突（Transverse process）
- 橫突孔（Foramen transversarium）

於樞椎（C2）上辨識（圖 1.12）：
- 棘突（Spinous process）
- 橫突（Transverse process）
- 橫突孔（Foramen transversarium）

解剖順序如下：
1. 辨識並追蹤枕大神經。
2. 翻開頭半棘肌。
3. 辨識構成枕下三角的肌肉。
4. 研究枕下區的內容物（椎动脉與枕下神經）。

### 解剖步驟

1. 再次辨識頭半棘肌（圖 1.11、1.13）：*[G 330; L 19, 20; N 170; R 238; C 377]*
2. 找出枕大神經穿頭半棘肌的位置。使用鈍剝將枕大神經向深層追蹤，穿過頭半棘肌。自枕骨處切斷頭半棘肌，向下翻開。保留枕大神經。
3. 於頭半棘肌深面，將枕大神經追蹤至下頭斜肌下緣。注意：枕大神經（ C2 後支）於 C1 與 C2 之間穿出。
4. 辨識並清理構成枕下三角邊界的三塊肌肉（圖 1.13）：*[G 333; L 20; N 172; R 238; C 385]*
   - **下頭斜肌（Obliquus capitis inferior）**：構成枕下三角的下界。確認其內側附著於樞椎（C2）棘突；外側附著於寰椎（C1）橫突。
   - **頭後大直肌（Rectus capitis posterior major）**：構成枕下三角的內側界。確認其內側附著於樞椎棘突；外側附著於枕骨下項線。
   - **上頭斜肌（Obliquus capitis superior）**：構成枕下三角的外側界。確認其下端附著於寰椎橫突；上端附著於枕骨上、下項線之間的骨面。
5. 構成枕下三角的肌肉可於寰枕關節處使頭部伸展及側屈，並於寰樞關節處使頭部旋轉。
6. 枕下三角的內容物為枕下神經與椎动脉（圖 1.13）。注意：枕下神經（C1 後支）於枕骨與寰椎（C1）之間穿出，支配枕下區肌肉的運動。枕下神經是頸椎脊神經後支中唯一沒有皮支分布者。
7. 辨識椎动脉。利用圖示研究椎动脉穿過頸部並進入顱內的路徑：*[G 335; L 13, 20; N 135; R 168; C 543]*

### 解剖後續

1. 複習枕下肌肉的功能。
2. 複習胸椎後支的分布方式，並比較頸椎後支的分布模式。

## VERTEBRAL CANAL, SPINAL CORD, AND MENINGES｜椎管、脊髓與脊膜

### 解剖概覽

椎管是由頸椎、胸椎、腰椎的椎孔及骶管堆疊而成的骨性管道（圖 1.14），容納並保護脊髓及其被膜（脊膜）與血管。

脊髓始於枕骨大孔，於成人通常終於第二腰椎水平。由於脊髓短於椎管，脊髓節段位於較其名稱所指更高的椎體水平（圖 1.14）。

脊髓的直徑並非全程一致，有位於 C4 至 T1 節段對應的**頸膨大**（cervical enlargement），以及位於 L2 至 S3 節段對應的**腰膨大**（lumbar enlargement）。脊神經共 31 對（8 對頸神經、12 對胸神經、5 對腰神經、5 對骶神經、1 對尾神經，圖 1.14），於相鄰椎骨之間穿出。

大多數脊神經依其穿過椎間孔時所在椎骨的上位椎骨編號（如 T1 脊神經在 T1 椎骨下方離開椎管）。然而頸椎區域例外——頸神經依其下位椎骨編號（如 C1 脊神經在 C1 椎骨上方離開椎管，而 C8 脊神經沒有對應的頸椎椎骨）。

解剖順序如下：
1. 移除豎脊肌，顯露椎骨椎板。
2. 切斷並移除椎板（椎板切除術，laminectomy），顯露脊膜。
3. 觀察脊膜並打開，顯露脊髓。

### 解剖步驟

#### 椎板切除術

本步驟自胸椎水平開始，向下延伸。將脊膜顯露後，觀察脊膜並打開以顯露脊髓。

1. 所有需使用鑿子、骨鋸或骨鉗的步驟，請配戴護目鏡。
2. 使用手術刀將兩側 T4 至 S3 的豎脊肌移除。必須將椎板完全顯露。使用鑿子刮除附著於椎板上的肌肉碎屑。
3. 使用鑿子或電動鋸，於棘突兩側切斷 T6 至 T12 的椎板。切口應位於椎板外側端，以寬廣顯露椎管。切割工具應與垂直線成 45 度角（圖 1.15）。
4. 使用手術刀切斷 T6–T7 及 T12–L1 之間的棘間韌帶。保留這些層級之間的棘間韌帶，以使中間的棘突保持連接。
5. 使用鑿子將含六個棘突及其椎板的整體撬出。硬膜（dura mater）將留於椎管內並與脊髓一同不受損傷。
6. 觀察移除標本深面的黃韌帶（ligamenta flava）。黃韌帶連接相鄰椎骨的椎板。
7. 繼續向下方進行椎板切除術。利用直視椎管來幫助正確定位。下腰椎與骶骨區域需特別注意，椎管於此處急劇彎向後（淺）方（圖 1.16A）。勿將鑿子或鋸子穿過骶骨，以免工具穿透直腸。
8. 椎板切除術完成後，應可見 T6 至 S2 椎體水平的硬膜後表面。

#### 脊膜（Spinal Meninges）

1. 椎板切除術完成後，顯露的是硬膜外（椎管內）間隙（epidural space），內含脂肪與靜脈。使用鈍剝清除硬膜外脂肪及椎內後靜脈叢：*[L 26; N 163; C 481]*
2. 辨識硬膜（dura mater）。硬膜囊於下方終於 S2 椎體水平（圖 1.16A）：*[G 338; L 22, 24; N 157; R 230; C 403]*
3. 於胸部區域，用鑷子提起硬膜皺襞，使用剪刀於其後正中線上切開一小口。將切口用剪刀向下延伸至 S2 水平。盡量在不損傷深層蛛網膜的情況下完成。
4. 辨識蛛網膜（arachnoid mater，圖 1.17B）。蛛網膜非常脆弱。於後正中線切開蛛網膜，顯露並觀察蛛網膜下腔。蛛網膜下腔在活體含腦脊髓液，但大體標本中則無：*[G 339; L 23; N 162; R 232; C 404]*
5. 翻開蛛網膜，觀察脊髓。脊髓完全被軟膜（pia mater）覆蓋，軟膜位於脊髓表面，無法與脊髓分離。
6. 辨識脊髓的以下特徵（圖 1.16A, B）：*[G 336; L 22, 24; N 157; R 230; C 403]*
   - **腰膨大**（Lumbar enlargement，脊髓節段 L2–S3）供應下肢神經。腰膨大位於下位胸椎水平。
   - **脊髓圓錐**（Conus medullaris，medullary cone）為脊髓末端，位於 L1–L2 椎體水平。
   - **馬尾**（Cauda equina，拉丁文意為「馬尾」，圖 1.16B）為下位椎管內前根與後根的集合。
   - **終絲內部**（Filum terminale internum，圖 1.16A, B）為軟膜構成的細絲，自脊髓圓錐尖端發出，終於 S2 椎體水平，於此被硬膜囊下端包裹。
   - **終絲外部**（Filum terminale externum， coccygeal ligament，圖 1.16A, B）由硬膜構成，內含 S2 以下延伸的終絲內部延續。終絲外部穿過骶管裂孔，附著於尾骨。
7. 軟膜形成兩條齒狀韌帶（denticulate ligament），位於脊髓兩側（圖 1.17A, B）。每條齒狀韌帶有 21 個齒狀突，各齒附著於硬膜內面，將脊髓固定。*[G 337; L 23; N 162; R 231; C 404]*
8. 使用探針追蹤後根與前根至其穿破硬膜並進入椎間孔之處（圖 1.17B）。後根位於齒狀韌帶的後面；前根位於齒狀韌帶的前面。脊神經將於椎管外側後根與前根會合之處形成。
9. 觀察沿前根與後根走行的細小血管。這些是後肋間动脉、腰动脉 或椎动脉的分支（視椎體水平而定），它們穿過椎間孔進入椎管，供應脊髓：*[G 342, 343; L 25; N 165; C 404]*
10. 於胸部區域，顯露一條脊神經。將探針插入椎間孔以保護其內的神經。使用骨鉗移除椎間孔後壁，顯露脊神經節（背根神經節，dorsal root ganglion，圖 1.17A）。於脊神經節遠端辨識脊神經，並向遠端追蹤至其分為後支與前支之處。

### 解剖後續

1. 複習典型脊神經的形成與分支。
2. 描述深層背部肌肉接受神經支配的方式。
3. 複習脊髓的被膜與組成，並研究顯示脊髓血液供應的圖示。
4. 參照皮節圖，將此種皮膚感覺神經分布模式與脊髓節段相關聯：*[G 348; L 27; N 159; C 372]*

## CLINICAL CORRELATIONS｜臨床相關

### 椎靜脈叢（Vertebral Venous Plexuses）

椎靜脈叢的靜脈無瓣膜，血液可依血壓梯度向上或向下流動。椎靜脈叢可作為癌症自骨盆腔轉移至椎骨、椎管及顱腔的路徑。

### 腰椎穿刺（Lumbar Puncture）

腦脊髓液（CSF）可於脊髓圓錐下方（圖 1.18）的蛛網膜下腔抽取。在此層級，穿刺針無刺穿脊髓的風險。
